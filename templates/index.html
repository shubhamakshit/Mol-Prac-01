How to Use the IUPAC Compounds Viewer

1. Import your compounds
You can either paste a JSON array of compound names or use the API Generator to create compounds.

2. Flip to reveal
Click on any compound card to flip it and reveal the IUPAC name.

3. Keyboard navigation
You can use the spacebar to flip the focused card or use Tab to navigate between cards.

4. Quiz Mode
Test your knowledge in an interactive guessing game.

Example JSON format:

[
  {"name": "2-methylbutane"},
  {"name": "4-aminobenzoic acid"}
]
